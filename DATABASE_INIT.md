# 🚀 Database Initialization Guide - MTNPDV

## Overview

The `app:init:database` command initializes the MTNPDV database with migrations and generates realistic fake data for 3 months of operational usage.

## Quick Start

### Option 1: Interactive Mode (Recommended)
```bash
php bin/console app:init:database
```
- ✅ Asks for confirmation before deleting data
- ✅ Prompts for fake data generation
- ✅ Shows summary of created data

### Option 2: Generate Fake Data Automatically
```bash
php bin/console app:init:database --with-data --force
```
- ✅ Skips confirmation prompts
- ✅ Automatically generates 3 months of fake data
- ✅ Ready for testing immediately

### Option 3: Database Only (No Fake Data)
```bash
php bin/console app:init:database --no-data --force
```
- ✅ Only creates database structure
- ✅ Creates base roles and categories
- ✅ No fake data generated

## Troubleshooting

### Error: "Foreign key constraint fails"
```bash
# Make sure database exists
php bin/console doctrine:database:create
php bin/console doctrine:migrations:migrate
php bin/console app:init:database --with-data
```

### Error: "Unique constraint violation"
```bash
# Reset and try again
php bin/console app:init:database --force --with-data
```

### Error: "Table doesn't exist"
```bash
# Run migrations first
php bin/console doctrine:migrations:migrate
php bin/console app:init:database --with-data
```
